In this folder all classes, scripts, and functions are stored to run the
TherMOS toolkit. In detail, the following folders exists:

1) data:        Includes all functions for data loading and processing
2) dev:         Includes all functions under development
3) general:     Includes all general functions 
4) model:       Includes all temperature modeling functions
5) plotting:    Includes all printing and plotting functionalities
